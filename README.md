# Portfolio Watch (Frontend)

React + Vite client for **Portfolio Watch**. Talks to **api-portfoliowatch-express**.

**Documentation:** **[docs/README.md](./docs/README.md)**

## Quick start

```bash
yarn
cp .env.example .env
# VITE_API_BASE_URL=http://localhost:3333
yarn dev
```
